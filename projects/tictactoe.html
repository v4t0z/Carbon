Yapay Zekalı Tic-Tac-Toe

Matris yapılarını ve algoritma mantığını oturtmak için geliştirdiğim klasik X-O oyunu.

nedir?

İki kişinin aynı bilgisayar üzerinden oynayabileceği veya bilgisayara karşı mücadele edebileceği, terminal tabanlı 3x3 matris oyun yapısıdır.

öne çıkan özellik // kazanma kontrolü

Her hamleden sonra dikey, yatay ve çapraz kombinasyonları tarayan minimalist kontrol döngüsü:

javascript // board.js ● active
const winPatterns = [
[0, 1, 2], [3, 4, 5], [6, 7, 8], // yataylar
[0, 3, 6], [1, 4, 7], [2, 5, 8], // dikeyler
[0, 4, 8], [2, 4, 6] // çaprazlar
];

bana kazandırdıkları

  • Çok boyutlu diziler (matrisler) ve koordinat sistemleri üzerinde tam hakimiyet kazandım.
  • Temel oyun döngüsü (`game loop`) ve durum yönetimini (state management) anladım.
