öne çıkan özellik // eval emülasyonu

Girdileri tehlikeli olan hazır `eval()` fonksiyonu yerine, regex kullanarak güvenli bir şekilde ayrıştıran algoritma mimarisi:

python // safe_calc.py ● active
import re

# girdiyi temizle ve güvenli şekilde parse et
def parse_expression(user_input):
tokens = re.findall(r'\d+\.?\d*|[\+\-\*/]', user_input)
return tokens
