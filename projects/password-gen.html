Rastgele Şifre Oluşturucu

Veri güvenliği mantığı ve kütüphane entegrasyonu üzerine yaptığım bir çalışma.

nedir?

Kullanıcının belirlediği uzunluk ve kriterlere (büyük harf, sayı, özel karakter) göre kırılması imkansıza yakın, kriptografik açıdan güvenli parolalar üreten bir sistemdir.

öne çıkan özellik // kriptografik rastgelelik

Tahmin edilebilir standart `random` kütüphaneleri yerine, işletim sistemi çekirdeğini kullanan `secrets` yapısı:

python // generator.py ● active
import secrets
import string

# kriptografik güvenli karakter seçimi
alphabet = string.ascii_letters + string.digits
password = "".join(secrets.choice(alphabet) for i in range(16))

bana kazandırdıkları

  • String (metin) manipülasyonu ve karakter setleriyle çalışmayı öğrendim.
  • Siber güvenlikte "sahte rastgelelik" (pseudo-random) ile "gerçek rastgelelik" arasındaki ölümcül farkı kavradım.
