# Personal Portfolio & Blog

A modern, high-performance personal portfolio and blog website built with Tailwind CSS and vanilla JavaScript. Features a fully integrated dark/light mode, a customized cyberpunk-themed system upgrade status indicator, and a dynamic scroll progress tracker for blog posts.

## Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS
- **Interactions:** Vanilla JavaScript

## Project Structure

```text
my-portfolio/
│
├── index.html          # Main landing page (Portfolio, Projects, Contact)
├── blog.html           # Detailed blog post template with progress bar
├── style.css           # Custom Tailwind and scrollbar overrides
├── script.js           # Theme switching and scroll progress mechanics
└── assets/             # Global assets (Favicon, images, and project files)
